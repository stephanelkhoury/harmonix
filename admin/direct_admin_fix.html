🛠️ Harmonix Admin Access Direct Fix

This tool applies a comprehensive fix to resolve the "Access denied" error when trying to access the admin dashboard.

What This Fix Does:

  1. Verifies admin privileges in your token
  2. Fixes inconsistencies between token and localStorage data
  3. Forces all API requests to use the correct server port (5001)
  4. Ensures proper Authorization headers are set for all requests
  5. Adds error monitoring to help diagnose any remaining issues
